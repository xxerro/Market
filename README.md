# دفتر الدين

تطبيق Flutter لإدارة مبيعات المتجر ومخزونه وديون الزبائن، بواجهة عربية. تُحفظ البيانات محليًا على الجهاز باستخدام SQLite.

## الميزات

- تسجيل المبيعات النقدية وتسجيل طريقة الدفع: نقدًا، جوال باي، بال باي، أو بنك فلسطين. اختيار الوسيلة يُسجل في كشف المبيعات؛ التطبيق لا ينفذ التحويل المالي بنفسه.
- إضافة المنتجات إلى السلة من قائمة المنتجات أو عبر مسح باركود وQR.
- إنشاء منتج جديد مباشرةً من الكاشير عند مسح باركود غير مسجل؛ يُضاف المنتج بعد حفظه إلى السلة.
- إدارة بيانات المنتجات وأسعارها وكمياتها، مع سجل لحركات المخزون وتنبيهات انخفاض المخزون.
- استيراد المنتجات من CSV، وإنشاء ملصقات QR.
- إدارة الزبائن والديون والدفعات، وعرض الأرصدة وكشوف الحساب ومشاركتها.
- تقارير للمبيعات والمقبوضات والديون والمخزون المنخفض.
- إنشاء نسخة احتياطية واستعادتها، مع إمكانية تفعيل رمز قفل للتطبيق.

## المتطلبات

- Flutter SDK وDart متوافقان مع القيود في `pubspec.yaml`.
- Android Studio أو Android SDK لتشغيل وبناء تطبيق Android.
- لا يحتاج تشغيل التطبيق إلى خادم أو اتصال شبكة لحفظ البيانات المحلية. مشاركة النسخ أو إرسال الرسائل قد تحتاج تطبيقات وخدمات خارجية.

## قواعد البيانات وتوليد Drift

ملفات قاعدة البيانات المولدة موجودة في `lib/data/db/app_database.g.dart`. عند تعديل جداول Drift، أعد توليد الشيفرة:

```bash
dart run build_runner build
```

## الاستخدام الأساسي

1. أضف المنتجات من تبويب **المنتجات** أو امسح باركودًا جديدًا واتبع نموذج الإضافة.
2. افتح تبويب **الكاشير** وأضف المنتجات بالمسح أو من القائمة.
3. اختر وسيلة الدفع وأكد البيع؛ تُحفظ العملية في كشف المبيعات وتُفرغ السلة للطلب التالي.
4. لتسجيل البيع بالدين، اختر **على الحساب** وحدد الزبون.
5. خذ نسخة احتياطية دوريًا من **الإعدادات** واحفظها خارج الجهاز.

## حفظ البيانات

بيانات المتجر محفوظة محليًا على الجهاز. حذف التطبيق أو فقدان الجهاز قد يؤدي إلى فقدان البيانات؛ صدّر نسخة احتياطية بانتظام واحفظها في مكان آمن. لا يتصل اختيار وسيلة الدفع بمحافظ أو بنك لتنفيذ التحويل، بل يسجل الوسيلة المختارة في الفاتورة وكشف المبيعات.
